# Product

## Platform
web

## Stack
User requested a single static HTML page hosted publicly with GitHub Pages.

## Purpose
Catalog Adolanium's public Hermes plugins with descriptions, available screenshots, installation guidance, repository links, search and category filters. Themes and pets are explicitly excluded. Refresh automatically for new public plugins.

## Constraints
Use only public repository data. Exclude Hermes core and development tools. Preserve documented installation instructions rather than inventing universal commands. No authorship credits in source or documents.

## Audience
Assumption: Hermes users choosing extensions to install.
