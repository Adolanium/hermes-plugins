# Product

## Platform
web

## Stack
A single static HTML page on GitHub Pages, generated by a dependency-free Node script. The same script writes the README gallery.

## Purpose
List every Adolanium plugin that is in the Hermes plugin catalog (NousResearch/hermes-agent `plugin-catalog/`), at its pinned version, with its banner, summary, install commands, catalog page and source. Refresh daily so new admissions and pin bumps appear without manual edits. Also list our other public repositories that ship a plugin.yaml, in a separate section clearly marked as outside the catalog and unreviewed.

## Appearance
Dark only, in the Nous Research portal style of the plugin banners.

## Constraints
Use only public data: the catalog entries and the plugins' repositories. Show the catalog's install commands rather than inventing others. No authorship credits in source or documents.

## Audience
Hermes users choosing plugins to install.
