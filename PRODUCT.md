# Product

## Platform
web

## Stack
User requested a single static HTML page hosted publicly with GitHub Pages.

## Purpose
Catalog Adolanium's public Hermes plugins with descriptions, available screenshots, installation guidance, repository links, search and category filters. Themes, pets and all forks are explicitly excluded. Refresh automatically for new public plugins.

## Appearance

Dark mode is the default, as requested.

## Constraints
Use only public repository data. Exclude Hermes core and development tools. Preserve documented installation instructions rather than inventing universal commands. No authorship credits in source or documents.

## Audience
Assumption: Hermes users choosing extensions to install.
