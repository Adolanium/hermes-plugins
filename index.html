hermes-resetwatch

Desktopv0.2.22@7131146c

Resetwatch

Track subscription quotas and reset times in Hermes Desktop.

hermes plugins install hermes-resetwatch hermes plugins enable hermes-resetwatch
What it touches

probe.py re-executes itself under the Hermes Python interpreter located via HERMES_PYTHON / VIRTUAL_ENV / the parent process or the Hermes installer's managed venv (HERMES_HOME/installs); it reads provider API keys from the Hermes .env, Hermes's own saved OAuth logins (auth.json credential pool, read-only), the Vaultwarden plugin's local secret cache (cache/vaultwarden_cache.json, read-only, only when Vaultwarden is the sole enabled secret source) and Docker s6 container env files, plus other coding-assistant CLIs' local logins (including macOS keychain entries), and sends each key only to its own vendor's usage endpoint.

devin

Toolsv0.1.1@bcfeeeb8

Hermes Devin

Delegate coding tasks to the Devin CLI, on your computer or in Devin Cloud, with live progress cards and change review in Hermes Desktop. Every launch goes through Hermes approval; Cloud runs need a separate Cloud-managed-permissions confirmation.

hermes plugins install devin hermes plugins enable devin
What it touches

spawns the vendor devin CLI from PATH or cli_path (devin acp, devin acp --cloud, devin --print, devin auth status, devin models list); the CLI edits files and runs shell commands in a folder the model picks (any folder unless allowed_roots is set) under the configured permission mode (accept-edits/smart auto-allow edits, dangerous auto-allows everything and needs allow_dangerous: true), and talks to Cognition's servers; Devin Cloud runs use Cognition-managed permissions that Hermes does not gate. Every model-initiated launch goes through Hermes approval; follow-ups typed on a Desktop run card and answers to Devin's prompts on the card start or allow actions on that click without a Hermes prompt (unanswered card prompts are denied after 300 s by default). Uses the existing Devin CLI login and stores no credentials; Hermes provider, bot and tool secrets are stripped from the child environment (extra_env is passed as set). Background runs continue after the turn up to their timeout and post Devin's output back into the conversation as a message when they finish. Run history (prompts, diffs, command output) and model preferences are saved under plugin-data/devin unless persist_runs is off. Independent community add-on, not affiliated with Cognition.

cloudflare-web-search

Webv1.0.1@a0ee6267

Cloudflare Web Search

Cloudflare Web Search backend for Hermes' existing web_search tool, with Ceramic, Exa, or Linkup selected in plugin settings. Search only; keep a separate extract backend.

Needs CLOUDFLARE_WEB_SEARCH_API_TOKEN

hermes plugins install cloudflare-web-search hermes plugins enable cloudflare-web-search
What it touches

sends queries, result limits, gateway IDs, and optional BYOK aliases to api.cloudflare.com, which forwards searches to the selected provider and records them in AI Gateway logs. Requests can consume gateway credits or provider quota. Reads its own settings and CLOUDFLARE_WEB_SEARCH_API_TOKEN through Hermes' profile-scoped APIs. Registers one web provider, with no new tools, hooks, background processes, file writes, or self-updater. Independent community plugin.

How installing works

01

Install

hermes plugins install <name> clones the plugin at the commit the catalog pins. Hermes Desktop has the same button on its catalog page.

02

Enable

hermes plugins enable <name> turns it on. Desktop plugins appear in the sidebar; agent tools and backends are picked up by the agent.

03

Update

New versions reach you only after a reviewed pin bump in the catalog. Then hermes plugins update <name> brings them in.
